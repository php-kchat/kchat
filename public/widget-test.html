Chat Widget Test Page

This page includes the KChat widget script for testing the embedded chat flow.

Important:
Make sure your Laravel app allows cross-origin POST requests from this page. In config/cors.php, keep the widget endpoints public, and ensure your frontend domain is allowed if needed.

For a local test page on another domain or localhost port, update the CORS config to allow that origin, or temporarily use the same host/domain for testing.

Required app URLs for the widget to work:
POST /widget/init
POST /widget/start-chat
POST /widget/send-message
POST /widget/poll
